# Безопасность

## Сообщить об уязвимости

Не публикуй реальные токены, cookie, приватные URL или диагностические файлы в открытом Issue.

Для уязвимости без чувствительных данных можно создать GitHub Issue с минимальным примером. Для приватного сообщения используй GitHub Security Advisories репозитория.

## Границы sanitizer

BugCapture скрывает известные чувствительные заголовки, query-параметры и распространённые форматы секретов. Это защита от типичных утечек, а не гарантия обнаружения любого секрета. Перед передачей отчёта другому человеку проверь содержимое TXT и safe HAR.
