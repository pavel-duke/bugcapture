# BugCapture 0.4.0

### Что нового

- локальный Network Explorer после остановки записи;
- поиск по URL, method, status и host;
- фильтры All, Errors, 2xx, 3xx, 4xx, 5xx, Failed и проблемные запросы;
- безопасная карточка запроса с headers, duration, resource type, timestamp и initiator;
- экспорт WEBM, TXT и safe HAR после просмотра результата.

### Безопасность

- sensitive field denylist для headers, query и вложенных Console objects;
- поддержка snake_case, kebab-case, camelCase, регистра и `X-*` headers;
- очистка URL credentials, fragment, signed URL, nested URL и encoded значений;
- лимиты глубины и размера Console, защита от cyclic object и огромных payload;
- ранняя очистка при сборе и обязательная финальная очистка preview/TXT/HAR;
- удалены `tabs`, `<all_urls>` и постоянные content scripts;
- добавлены Gitleaks, CodeQL, Dependabot, bundle check, SBOM и SHA-256.

### Исправления

- закрыт обход sanitizer через вложенный JSON и чувствительные object fields;
- обычный UUID не скрывается без чувствительного контекста;
- готовые файлы по-прежнему скачиваются через service worker, а не offscreen document.

### Проверки

- 291 автоматический тест, включая 267 security regression-кейсов;
- format, lint, typecheck и production build;
- `npm audit`: HIGH/CRITICAL уязвимостей нет;
- Gitleaks 8.30.1: реальных секретов в полной истории не найдено;
- production bundle: нет `eval`, remote code, trackers и скрытого outbound traffic;
- ZIP проверен по allowlist состава, SHA-256 приложен отдельно.

Request body и response body не собираются. `Network.getResponseBody` не используется. Все данные остаются на устройстве пользователя.

> Для установки скачайте `BugCapture-v0.4.0-chromium.zip`, сверьте SHA-256, распакуйте архив и загрузите папку как распакованное расширение.
