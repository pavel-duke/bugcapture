# Интерфейс BugCapture 0.4

BugCapture использует общую визуальную основу с ReqVault: одинаковые дизайн-токены, системный шрифт, SVG-иконки и правила доступности. В версии 0.3 интерфейс намеренно сведён к одному действию на каждом этапе.

## Основные правила

- шаг сетки — 4 px, основные интервалы — 8/12/16/20/24 px;
- главный акцент — фиолетовый, красный используется только для записи и ошибок;
- до начала записи показывается одна главная кнопка без карточек и технических счётчиков;
- системный шрифт не требует загрузки внешних ресурсов;
- таймер и числовая статистика используют табличные цифры;
- состояние дублируется текстом, формой и иконкой, а не передаётся только цветом;
- все кнопки имеют заметный `focus-visible`;
- анимации короткие и отключаются через `prefers-reduced-motion`;
- иконки находятся в коде и построены на сетке 24×24;
- интерфейс не зависит от сети, внешних шрифтов и icon CDN.

## Состояния popup

1. **Ready** — текущая вкладка и одна кнопка начала записи.
2. **Recording** — таймер, отметка момента и остановка.
3. **Processing** — короткий статус подготовки файлов без лишних действий.
4. **Completed** — краткая сводка, переход в Network Explorer и экспорт пакета.
5. **Error** — компактная ошибка с конкретным текстом без технического шума интерфейса.
6. **Network Explorer** — отдельный локальный экран с поиском, компактными фильтрами, списком запросов и прокручиваемой карточкой безопасных деталей.

Product screenshot создаётся командой `npm run screenshot` из production build.
