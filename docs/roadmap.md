# Roadmap BugCapture до 1.5.0

Это планы, а не список готовых функций. Возможности ниже пока не реализованы и могут меняться после обратной связи пользователей.

## 0.4.0 — Network explorer

- поиск и фильтры по Network-запросам;
- группировка по HTTP-статусам;
- отдельный список failed requests;
- компактный просмотр запроса без чувствительных данных.

## 0.5.0 — Просмотр диагностики

- Timeline, Network и Console в одном локальном просмотрщике;
- быстрый переход к отмеченным моментам;
- сводка ошибок перед скачиванием;
- экспорт выбранной части отчёта.

## 0.6.0 — Усиленный sanitizer

- настраиваемые правила очистки;
- preview скрытых полей без показа самих секретов;
- дополнительные форматы API-ключей и токенов;
- тестовый режим проверки правил.

## 0.7.0 — Расширенный HAR

- полные timings и redirects;
- initiator запроса;
- более точные размеры ресурсов;
- импорт safe HAR обратно в локальный просмотрщик.

## 0.8.0 — Опциональные bodies

- сбор выключен по умолчанию;
- поддержка только разрешённых JSON-данных;
- лимиты размера и строгая очистка;
- явное предупреждение перед включением.

## 0.9.0 — Подготовка к стабильной версии

- единый diagnostic bundle;
- проверка восстановления после сбоев;
- тесты длительных записей и больших сессий;
- финальная проверка форматов экспорта.

## 1.0.0 — Стабильный релиз

- стабильные форматы отчётов;
- privacy и security review;
- accessibility и keyboard review;
- документация для пользователей и разработчиков.

## 1.1.0 — Firefox

- адаптер WebExtensions для Firefox;
- проверка различий записи вкладки и Network;
- отдельная сборка и инструкция установки.

## 1.2.0 — Шаблоны для команд

- готовые форматы описания бага для GitHub Issues и трекеров;
- выбор состава экспортируемого отчёта;
- локальные пользовательские шаблоны;
- копирование краткой сводки без секретов.

## 1.3.0 — Доступность и локализация

- полная навигация с клавиатуры;
- улучшенная поддержка скринридеров;
- русский и английский интерфейс;
- проверка контраста и масштабирования.

## 1.4.0 — Производительность

- снижение потребления памяти на длинных записях;
- безопасные лимиты Network и Console;
- понятные предупреждения о размере сессии;
- тесты слабых компьютеров и больших вкладок.

## 1.5.0 — Готовность к широкому использованию

- подготовка публикации в каталогах браузеров;
- проверяемые и воспроизводимые релизные сборки;
- расширенная совместимость Chromium-браузеров;
- стабильная политика обновлений и миграций.

Планы не содержат обещанных сроков. Незавершённые функции не включаются в релиз ради номера версии.
