# Участие в BugCapture

Спасибо за желание помочь проекту.

## Перед началом

1. Создай Issue с описанием проблемы или предложения.
2. Не прикладывай raw HAR, реальные токены, cookie и внутренние URL.
3. Для бага укажи браузер, его версию, ОС и короткие шаги воспроизведения.

## Локальная проверка

```bash
npm ci
npm run verify
```

Pull request должен проходить lint, typecheck, tests и production build.

## Коммиты

Пиши короткие сообщения на русском языке, например:

```text
feat: добавляю фильтр сетевых ошибок
fix: очищаю токен в query-параметре
docs: уточняю установку в Яндекс Браузере
test: проверяю удаление Authorization
```

## Приватность

Изменения, которые добавляют сбор новых данных, должны быть явно описаны и выключены по умолчанию. Телеметрия, аналитика и автоматическая отправка файлов не принимаются.
